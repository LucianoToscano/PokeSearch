# Auditoria incremental v0.54
Base v0.53-beta preservada; novos overlays separados via `groupRoots[3]`, `groupParams[3]`, `groupPanels[3]`; posições gravadas individualmente em SharedPreferences. CSS e JS da janela de resultados isolam `groupId`, usam `profileIndex`, sem reproduzir todos os resultados na janela principal. Alça transparente de 24dp recebe somente gestos de arraste, não os toques nos sprites. `resizeGroup` mede a altura de cada lista; limpeza no onDestroy inclui três WebViews.
Eye: preferências booleanas de contagem, temporizador, nível, PC, IV, rank; padrão do toolbar vertical/texto para preferências novas, respeita escolhas antigas salvas. Modos rápidos mapeados para busca IV100, IV000, GL, UL e personalizado.
Riscos/validação: WebView visível com transparência real, painel arrastável no sistema de overlays Android, múltiplas janelas Android 15/16, layout com teclado e orientação, dados de rank site oficial, coordenadas a partir do resultado certo. Não usar fontes de rank inventadas. O arquivo é uma auditoria de código, não certificação de testes físicos.
